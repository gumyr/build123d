#############
How-to Guides
#############

How-to guides are **goal-oriented**. Each one starts from something you want
to get done - sketch an outline, select a set of edges, add a flange, export a
drawing - and gives the directions for doing it.

They assume you already know the basics of build123d and know what you want to
achieve, so they do not teach concepts or describe every option. For a guided
introduction see the :ref:`tutorials <tutorials>`; for the complete details of
an object or operation see the :ref:`reference <reference_section>`; and for
the reasoning behind how build123d works see the
:ref:`explanation <explanation>`.
