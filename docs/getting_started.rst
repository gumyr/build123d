###############
Getting Started
###############

This section takes you from nothing to a first working model. It is the
shortest route to having build123d installed, a part on the screen and an
idea of where to go from there, and it assumes no knowledge of build123d.

It deliberately explains very little. Each page asks you to do one thing and
shows what to expect when it has worked; the reasons behind what you are doing
are left to the sections that follow.

.. note::

    build123d models are Python scripts, so this section assumes that Python
    is installed and that you know how to run a script. If Python is new to
    you, start with the
    `Beginner's Guide to Python <https://wiki.python.org/moin/BeginnersGuide>`_
    on python.org and come back here afterwards.
